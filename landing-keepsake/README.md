# Keepsake – landing page

Demo: https://<ваш-логін>.github.io/landing-keepsake/

Responsive one-page landing for the Keepsake design agency, built from a Figma layout.

## Technologies
- Semantic HTML5 (header, nav, main, section, article, footer, form), one `h1`
- CSS only: custom properties (`:root`), Flexbox, CSS Grid for the portfolio
- Mobile first, `@media (min-width: 768px / 1280px)`
- CSS-only burger menu and portfolio filter (`:checked ~`)
- Inline SVG icons, WebP images with `loading="lazy"`
- Google Fonts: Oswald, Open Sans, Dancing Script (`font-display: swap`)
- Accessibility: keyboard focus styles, `aria-label`, `alt`
